# مستشار المحامص والمطاحن — النسخة الأولية

تطبيق متعدد المنصات مبني باستخدام Expo وReact Native، بواجهة عربية واتجاه عرض مناسب للمحتوى العربي.

## ما يتضمنه النموذج
- صفحة رئيسية وأقسام: القهوة، البهارات، المكسرات، التتبيلات.
- هيكل مكتبة الخلطات.
- فهرس أكاديمية تعليمية.
- حاسبة تحويل مقادير الوصفات من أساس 1 كجم.
- واجهة لوحة مدير توضيحية.

## تشغيل المشروع
يتطلب تثبيت Node.js وبيئة Expo:
```bash
npm install
npx expo start
```
يمكن تجربة التطبيق عبر Expo Go على الهاتف أو محاكي Android/iOS.

## مهم قبل الإطلاق التجاري
هذه نسخة واجهة أولية وليست خدمة جاهزة للنشر التجاري. لا تحتوي بعد على:
- تسجيل دخول حقيقي أو صلاحيات آمنة للمالك.
- قاعدة بيانات سحابية أو تخزين فيديوهات.
- بوابة دفع أو تحقق من الاشتراك.
- حماية محتوى الخلطات على الخادم.
- إعدادات النشر النهائية ومتطلبات متاجر التطبيقات.

يجب تنفيذ هذه المكونات قبل استقبال اشتراكات حقيقية. لا تعتمد على إخفاء الأزرار في التطبيق كوسيلة لحماية الوصفات؛ يجب فرض الصلاحيات في الخادم وقاعدة البيانات.
